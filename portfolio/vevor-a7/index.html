Projects / Engineering

Bringing a bricked laser back to life

A budget laser engraver with closed firmware, an undocumented board and no way to run it wirelessly. Three days of reverse engineering later: open firmware, LightBurn over Wi-Fi, jobs from an SD card — and the first published solution for this hardware.

The problem

The VEVOR A7 10W ships with locked vendor firmware: no home Wi-Fi, a crippled network protocol, no SD workflow. The controller inside is an AtomStack YZ-102 — an ESP32-S3 board with no public documentation at all. Owners of bricked machines were stuck: community forum threads ended with "nobody has a working firmware for this board".

The process

No schematics, so the board gave up its secrets one measurement at a time:

  • Full flash backup first — every step stayed reversible
  • MicroPython as a diagnostic REPL living on the board itself
  • Motors turned out to hang off a 74HC595 shift register — found by voltage bisection with a multimeter, not a logic analyzer
  • A hidden hardware watchdog: the stepper drivers ignore everything until a charge pump is fed a continuous square wave — and one axis needs minutes to wake, which looks exactly like dead hardware
  • The laser pin boots frozen by a hardware HOLD; the firmware has to release it or the diode glows at power-on
  • An upstream grblHAL bug killing PWM on ESP32-S3 — found, fixed, and submitted back to the project

The result

Custom grblHAL firmware purpose-built for this board: homing, laser control, Wi-Fi with a permanent address, LightBurn over the network, SD card jobs with automatic homing — and a self-hosted web remote that runs on the controller itself, so any phone on the network can start, pause and stop jobs.

The full hardware map, firmware and guide are published as open source — the first public solution for this controller.
